# 55. 그림 큐브(센터 방향까지 맞추기) 계획

2026-11-26 사용자가 하기로 정했다. 토큰에 여유가 생기면 하는 「미뤄 둔 큰 일」이고, 이 문서는 그때 바로 시작할 수 있게 범위·순서·정할 것을 적어 둔다. 시작하는 세션은 이 문서와 `docs/standing-rules.md`를 먼저 읽는다.

## 1. 무엇을 만드나

각 면에 방향이 보이는 무늬(화살표·그림 등)가 있어, 조각의 자리뿐 아니라 **센터 블럭의 방향까지** 맞아야 다 맞은 것으로 보는 3×3 큐브다. 일반 큐브는 센터 블럭이 돌아가 있어도 색이 같아 알 수 없지만, 그림 큐브는 돌아간 것이 보인다.

- 사용자 결정: 지도에 섞지 않고 **큐브 「종류」(일반 / 그림)** 로 둔다.
- 처음 범위는 3×3만이다. 2×2는 센터가 없어 달라지는 것이 없다. 4×4 이상은 센터 조각이 여럿이라 나중에 따로 본다.

## 2. 이미 있는 것

- 엔진 상태가 스티커 방향(`twist`)을 처음부터 들고 다닌다(docs/47 2-1).
- 맞춤 판정에 `orientCenters` 선택이 있다(`packages/cube-engine/src/state.ts` 67줄).
- 큐브의 수학 카드가 그림 큐브 경우의 수 「4⁶÷2배」를 이미 다룬다(docs/47 0절).
- 없는 것: 무작위 상태가 센터 `twist`를 늘 0으로 둔다(`random.ts` 285줄). 그래서 그림 큐브 섞기는 아직 안 된다.

## 3. 할 일(차례대로)

1. **자료 확인**(고정 규칙 2-1 「실제 물건은 자료로」)
   - 센터 방향의 짝 조건: 돌아간 양의 합이 180°의 배수가 되는지 확인한다.
   - 센터 방향을 고치는 공식: 센터 하나 180°, 둘을 90°씩 반대로 등.
   - 흔한 그림 큐브 무늬. 출처는 docs에 남긴다.
2. **엔진**
   - 그림 큐브 무작위 상태: 센터 `twist`도 짝 조건 안에서 섞는다.
   - 섞기 글을 만든다.
   - 판정은 `orientCenters`로 한다.
   - 웹 엔진과 Rust 코어(`native/cube-core`)가 같은 값을 내게 공통 시험 자료를 둔다.
3. **그리기**
   - 3D 스티커에 방향이 보이는 무늬를 그린다.
   - 정지 그림·포스터를 만든다.
   - Cubie 네이티브 큐브 창도 웹과 함께 그린다(고정 규칙 5절 웹·네이티브 함께, 비교 그림).
   - 무늬 시안은 사용자에게 로컬에서 먼저 보인다.
4. **종류 고르기**
   - 「지금 크기」(docs/47 16-28) 옆에 「종류」를 두고 함께 기억한다.
   - 그림은 3×3에서만 고를 수 있다.
   - 하는 화면 / 보는 화면 규칙은 크기와 같다.
5. **혼자 맞추기·기록**
   - 그림 3×3 기록은 일반과 따로 쌓는다(저장 키에 종류).
   - 티어는 아래 「정할 것」을 따른다.
6. **배우기**
   - 「센터 방향 맞추기」 단원 하나를 둔다. 무엇이 다른지, 짝 조건, 공식 둘셋, 해 보기로 구성한다.
   - 해법 지도는 그림 종류일 때만 「다 맞음」 앞에 「센터 방향」 걸음을 붙인다. 4×4 토끼이빨 고리처럼 「그림 큐브에만 있는 걸음」으로 보인다.
   - 공식 연습에 센터 방향 상황을 넣을지는 단원을 만든 뒤 본다.
7. **컴퓨터·대결**
   - 컴퓨터 해법에 마지막 센터 방향 단계를 더한다.
   - 대결방 「종류」 설정을 둔다.
   - 공정성은 지금 대결과 같다(같은 섞기, 기록으로 다시 계산).

## 4. 사용자가 정할 것(시작할 때 묻는다)

- 무늬: 화살표 같은 단순 무늬인지, 그림·사진 같은 것인지. 시안 몇 개를 보고 고른다.
- 그림 3×3에 티어를 따로 둘지, 기록만 둘지.
- 대결·컴퓨터 대결까지 넣을지, 혼자 맞추기와 배우기만 할지.

## 5. 크기와 끝 기준

- 대략 크기: 서브에이전트 네다섯 번(엔진·코어, 그리기·네이티브, 종류·기록, 배우기·지도, 컴퓨터·대결).
- 끝 기준
  - 그림 3×3을 골라 섞고, 센터 방향까지 맞추면 기록이 남는다.
  - 배우기 단원과 지도 걸음이 있다.
  - 웹과 Cubie 앱이 같은 그림을 그린다.
  - 위 시험(웹·코어 같은 값, 판정, 짝 조건)이 있다.
